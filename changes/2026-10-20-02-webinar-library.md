# 02 · Install the webinar library

**File:** `dist/webinar-library.html` (paste the whole file)
**Needs:** Squarespace Core plan or higher (check Settings, Billing). The current webinar list is a store category, which cannot hold a Code Block, so the library goes on its own page.

## Steps
1. **Pages > +** add a blank page named **Webinars** in the *Not linked* section (hidden from the menu). Address: `/webinars`.
2. Edit the page, **Add Block > Code**, turn **off** "Display Source", paste the whole file, **Save**.
3. Open `https://www.childnutritioncouncil.com/webinars` in a private window, logged out.
4. When staff are happy, link it: add it to the navigation, and add a "Search all webinars" button on the Resource Hub.

## Check
- 9 webinars show; typing "stigma" narrows the list; a filtered view's address can be copied and reopened.
- If the block looks empty while logged in, that is normal; check logged out.
- If the page shows only a link to the Resource Hub, scripts are not running: the plan is below Core.
